Постановка на чат-бота для организации мини-турниров по тенису в мессенджере Telegram.
Как должен выглядеть пользовательский путь:
1) Пользователь открывает чат-бот
2) Начинает сессию. Ему предлагается: создать мини-турнир, просмотреть список турниров
3) При создании мини-турнира идёт следующий диалог
3.1) Запрос количества участников. После ввода пользователю предлагается выбрать один из доступных форматов проведению турнира при таком количестве участников.
3.2) Если пользователь отказывается, то его перекидывает опять на главное меню. Если пользователь выбирает один из форматов, то ему предлагается ввести участников последовательно, одного за другим.
3.3) После ввода участников предлагается провести автоматическую жеребъёвку или же сформировать турнирую сетку в соответствии с последовательностью введенных игроков.
3.4) После этого выводится турнирная сетка в виде изображения
4) Если при старте диалога был выбран пункт просмотреть список турниров
4.1) Пользователя спрашивают за какие даты. По умолчанию стоит текущая неделя с понедельника по воскресенье.
4.2) Выводится список турниров, пользователь выбирает нужный или переходи на старт диалога.
4.3) При выборе турнира показывается изображение с турнирной сеткой и результатами на текущий момент.
4.4) Доступны возможности:  доступно указать что турнир начался, ввести результат одной из игр (если статус турнира - начался), доступно замена одного из игроков в сетке (если турнир в статусе - формирования)
4.4) Возможность ввести результат одной из игр, для этого можно запросить список пар игроков, пользователь выбирает нужную и вводит счёт, например: 3 4
4.5) Возможность заменить одного из игрока - выдаётся список игроков в сетке и пользователь может выбрать нужного, после чего написать нового, который заменит выбывшего.
4.6) Так же можно запросить красивый итоговый результат - это отдельная картинка формирующаяся на основании итоговой сетки.
5) Один из режимов турнира - свободный. Когда сетка заранее определить нельзя и игроки просто играют друг с другом и вводят результат. Эти результаты красиво выводяться в общую таблицу.

Особенности реализации:
Telegram бот должен быть написан на python. Бот можно использовать не только отдельно, но и в каком-нибудь чате (группе), куда он подключен. Но в группе можно запросить только турнирную сетку для выбранного турнира.
На сервере, хранить информацию о турнирах, для начала можно в json файлах. каждый турнир в своём.
Нужно предложить вариант как сформировать на сервере красивую турнирную таблицу для мини игр по теннису.
Мини игры как правило проводяться среди 8,9 или 12 человек, по общей длительности около 3 часов, на 2-х или 3- кортах одновременно.
